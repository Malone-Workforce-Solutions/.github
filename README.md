# .github

Org-wide defaults for Malone-Workforce-Solutions. GitHub applies the files here to every repo in the org that doesn't have its own.

- `pull_request_template.md`: the default PR template.

This repo is **public** because GitHub only applies org-wide PR and issue templates from a public `.github` repo. Nothing sensitive belongs here. Engineering rules, scripts, and the member-only org profile live in the private `.github-private` repo.

**Owner:** `@Malone-Workforce-Solutions/platform`. Change these files through a PR; if you change the PR template, update the matching body format in `.github-private/claude/managed-instructions.md` too.
